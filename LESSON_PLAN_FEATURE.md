# Функция "Структура урока с напоминаниями"

## Что это?

Новая функция позволяет создавать детальную структуру урока с автоматическими напоминаниями по времени. Вы можете заранее спланировать все шаги урока, и система будет напоминать вам о каждом шаге в нужное время.

## Как это работает?

### 1. Создание структуры урока

При добавлении или редактировании урока вы увидите новые поля:

- **Время урока** - укажите во сколько начинается урок (например, 14:00)
- **Структура урока (напоминалки)** - добавьте шаги урока

### 2. Добавление шагов

Каждый шаг урока содержит:

- **Описание** - что нужно сделать (например: "проверь дз и ссылка", "открой этот ресурс чтобы проработать с учеником")
- **Минуты** - через сколько минут от начала урока показать этот шаг (например: 0, 10, 25, 45)
- **Ссылка (опционально)** - любая ссылка на ресурс, которую нужно будет открыть

### 3. Пример структуры урока

**Урок:** Adult A1 - Present Simple
**Время:** 15:00
**Структура:**

1. **Шаг 1** (0 минут)
   - Описание: проверь дз по ссылке
   - Ссылка: https://progressme.ru/classroom/1904598/homework/16234518

2. **Шаг 2** (10 минут)
   - Описание: открой этот ресурс для практики вопросов
   - Ссылка: https://englishweb.ru/grammar/present-simple-exercises.html

3. **Шаг 3** (30 минут)
   - Описание: закрепи материал устно с учеником
   - Ссылка: (нет)

4. **Шаг 4** (50 минут)
   - Описание: задай домашку во Взнании
   - Ссылка: https://student.vznaniya.com/lesson/9873198

## Как работают напоминания?

1. **Разрешите уведомления** в браузере (появится запрос при первом использовании)

2. **В день урока** система автоматически:
   - Показывает браузерное уведомление за 1 минуту до каждого шага
   - Показывает напоминалку в правом нижнем углу экрана
   - При клике на уведомление автоматически откроет ссылку (если она указана)

3. **Напоминания работают**, если:
   - Браузер открыт
   - Разрешены уведомления
   - Дата урока совпадает с текущей датой
   - Указано время урока

## Советы по использованию

1. **Планируйте заранее** - создавайте структуру урока накануне
2. **Указывайте точное время** - напоминания привязаны ко времени начала урока
3. **Добавляйте все нужные ссылки** - так вы не забудете открыть нужный ресурс
4. **Используйте описания** - пишите понятные действия ("открой презентацию", "проверь упражнение 3")

## Преимущества

✅ Не нужно держать в голове весь план урока
✅ Не забудете ни один важный шаг
✅ Все ссылки под рукой в нужный момент
✅ Можно использовать одну и ту же структуру для похожих уроков (скопировать при редактировании)
✅ Браузерные уведомления работают даже если вы в другой вкладке

## Технические детали

- Напоминания проверяются каждые 30 секунд
- Уведомление показывается за 1 минуту до времени шага
- Время шага = время начала урока + количество минут из настройки шага
- Данные хранятся в базе данных (PostgreSQL через Supabase)
- Работает на всех современных браузерах с поддержкой Notification API

## Поддержка

Если у вас возникли вопросы или проблемы с новой функцией, проверьте:

1. Разрешены ли уведомления в браузере (настройки браузера)
2. Указано ли время урока
3. Добавлены ли шаги в структуру урока
4. Совпадает ли дата урока с текущей датой
