# 📱 Инструкция по добавлению студентов в Telegram бот

## 🎯 Обзор

Telegram бот позволяет автоматически отправлять домашние задания студентам. Каждый студент (или родитель) создаёт группу в Telegram и привязывает её к своему профилю в системе.

## 📋 Новые команды бота

### Для всех:
- `/start` - начать работу с ботом и увидеть список команд
- `/myid` - узнать ID текущего чата (полезно для отладки)
- `/findstudent ИМЯ` - найти студента по имени и получить его ID

### Для групп:
- `/link STUDENT_ID` - привязать группу к студенту
- `/status` - проверить статус привязки группы
- `/unlink` - отвязать группу от студента

## 🚀 Пошаговая инструкция для добавления студента

### Шаг 1: Создать группу в Telegram

1. Откройте Telegram
2. Создайте новую группу (например, "Английский - Иван Иванов")
3. Добавьте в группу:
   - Родителя (если студент несовершеннолетний)
   - Студента (опционально)
   - Преподавателя (опционально)

### Шаг 2: Добавить бота в группу

1. В группе нажмите на название группы → "Добавить участника"
2. Найдите бота по имени: `@YourBotName` (уточните у администратора)
3. Добавьте бота в группу

### Шаг 3: Найти ID студента

**Вариант А: Используя команду бота**
1. В группе напишите: `/findstudent Иван`
2. Бот покажет список студентов с похожим именем
3. Скопируйте ID нужного студента

**Вариант Б: Через веб-интерфейс**
1. Зайдите на https://tutorsdesk.ru
2. Перейдите в раздел "Студенты"
3. Найдите нужного студента
4. ID студента можно найти в адресной строке или в настройках студента

### Шаг 4: Привязать группу к студенту

1. В группе напишите: `/link STUDENT_ID`
   Например: `/link ffba0136-0b12-4f10-85b0-3d57f4259399`
2. Бот подтвердит успешную привязку

### Шаг 5: Проверить привязку

1. Напишите в группе: `/status`
2. Бот покажет информацию о привязке

### Что делать если студент уже привязан к другой группе?

1. Зайдите в старую группу
2. Напишите: `/unlink`
3. Вернитесь в новую группу
4. Напишите: `/link STUDENT_ID`

## 🔧 Устранение проблем

### Бот не отвечает?
1. Проверьте, что бот добавлен в группу
2. Убедитесь, что бот имеет права на отправку сообщений
3. Попробуйте написать `/start`

### Не можете найти студента?
1. Проверьте правильность написания имени
2. Попробуйте искать по части имени (например, "Алекс" вместо "Александр")
3. Используйте веб-интерфейс для поиска ID

### Ошибка при привязке?
1. Убедитесь, что команда вызвана в группе, а не в личном чате
2. Проверьте правильность ID студента
3. Убедитесь, что студент не привязан к другой группе
