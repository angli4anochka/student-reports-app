## 🔐 Безопасность и Изоляция Данных

### Многоуровневая изоляция (Multi-tenancy)

Система поддерживает трёхуровневую изоляцию:

**Супер-администратор** (без школы, `school = null`):
- Видит **ВСЕ данные из ВСЕХ школ**
- Может управлять всеми пользователями системы
- Неограниченный доступ

**Администраторы школ** (с привязкой к школе, `school` field):
- Видят **всех учеников, группы, оценки, расписание всех учителей своей школы**
- Могут управлять пользователями своей школы
- Данные других школ полностью изолированы

**Учителя**:
- Видят **только своих учеников, группы и оценки**
- Не видят данные других учителей (даже из той же школы)

### Примеры изоляции:

**Супер-администратор** (`school: null`):
- `superadmin@system.com` видит ВСЕХ учеников из ВСЕХ школ
- Видит данные от всех учителей (Алины, teacher1, teacher2, teacher3, demo)
- Полный доступ ко всей системе

**Школа 1** (`school: "school1"`):
- `admin1@school1.com` видит всех учеников от `alina.malakhova@school.com`, `teacher1` и `teacher2`
- `teacher1@school1.com` видит только своих учеников
- `teacher2@school1.com` видит только своих учеников
- `alina.malakhova@school.com` видит только своих учеников (17 человек)
- НЕ видят ничего из Школы 2

**Школа 2** (`school: "school2"`):
- `admin2@school2.com` видит всех учеников от `teacher3`
- `teacher3@school2.com` видит только своих учеников
- НЕ видят ничего из Школы 1

### Роли

1. **ADMIN** - Администратор
   - **С указанием школы** (`school` ≠ null):
     - Администратор конкретной школы
     - Видит **всех учеников учителей своей школы**
     - Может управлять пользователями своей школы
   - **Без школы** (`school` = null):
     - **Супер-администратор**
     - Видит **ВСЕ данные из ВСЕХ школ**
     - Может управлять всеми пользователями системы
   - Имеет доступ к админ-панели
   - Может назначать школу при создании новых пользователей

2. **TEACHER** - Учитель
   - Видит только своих учеников и группы
   - Может добавлять учеников, группы, оценки, расписание
   - Не имеет доступа к админ-панели
   - Может быть назначен к школе администратором

## 🚀 Как использовать

### Для портфолио

Используйте демо-аккаунт:
```
Email: teacher@demo.com
Пароль: demo123
```

Или любой из учительских аккаунтов для демонстрации полного функционала.

### Для школы

Каждая школа получает:
1. **Аккаунт администратора** - для управления учителями
2. **Аккаунты учителей** - для работы с учениками

Администратор может создавать новых учителей через **Админ-панель** (вкладка "⚙️ Админ-панель").

## 📊 Функционал для тестирования

### 1. Управление учениками
- Добавление/редактирование/удаление учеников
- Группировка по группам
- Заметки к ученикам

### 2. Система оценок
- Выставление оценок по критериям
- Комментарии и рекомендации
- Домашнее задание
- Прикрепление файлов

### 3. Расписание и уроки
- Создание расписания по группам
- Запись тем уроков
- Домашние задания

### 4. Посещаемость
- Календарь посещаемости
- Отметки: присутствие, отсутствие, опоздание
- Фильтрация по группам и датам

### 5. Экспорт в Excel
- Кнопка "📊 Экспорт в Excel" в шапке
- Экспорт всех данных в один файл
- 6 листов: ученики, группы, оценки, посещаемость, уроки, критерии

## 🔄 Сброс демо-данных

Если нужно пересоздать демо-аккаунты, запустите скрипт:

```bash
cd backend
npx ts-node scripts/seed-demo-accounts.ts
```

Скрипт использует `upsert`, поэтому:
- ✅ Безопасно запускать повторно
- ✅ Не создаст дубликаты
- ✅ Обновит существующие записи
